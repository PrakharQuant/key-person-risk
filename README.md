# Key Person Risk Index (KPRI)

Sectoral index measuring abnormal stock returns around CEO/CFO departures.

**Live case (not in sample)**: Nvidia Nov 2026 — Jensen Huang resigned; stock ~-13% at open 12 Nov.

## Quick start
```bash
make all
```
Site builds to `docs/` (GitHub Pages).

**This is research, not investment advice.**

See PLAN.md for architecture and METHODOLOGY.md (coming in later phases).
